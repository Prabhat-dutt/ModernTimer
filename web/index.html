Getting Started

Installation Guide

⚡ Recommended • Fast Setup

One-Click .rmskin Package

The simplest way to install ModernTimer. Rainmeter handles configuration automatically.

1
Download Package

Get the official ModernTimer_1.0.rmskin release package.

2
Run Skin Installer

Double-click the downloaded file to launch Rainmeter's automated package installer.

3
Click Install

Confirm installation. ModernTimer will immediately appear ready to use on your desktop!

Download ModernTimer v1.0 (.rmskin)
🛠️ Manual / Git Clone

Manual Source Installation

Ideal for customization or setting up directly from source code.

1
Clone Repository

Clone the code directly into your Rainmeter skins directory:

git clone https://github.com/Prabhat-dutt/ModernTimer.git
2
Open Rainmeter Manager

Right-click any active Rainmeter skin or system tray icon and select Manage.

3
Load Widget

Expand the ModernTimer folder, select TimerWidget.ini, and click Load.
